# 美国驾驶学习图鉴 · SVG 图集

这些 SVG 是从 `../us-driving-guide.html` 里的交互图解按「每一步 / 每一种状态」导出的独立文件（浅色主题，样式已内联，可直接在浏览器、Keynote、Figma 或 Anki 卡片里使用）。

| 文件夹 | 内容 |
| --- | --- |
| `01-history/` | 1886 → 2020s 共 12 个年代的汽车与关键技术 |
| `02-driving-logic/` | 4 个年代的驾驶舱、三种刹车方式（抱死 / 点刹 / ABS）、三种握方向盘方式 + 气囊、SAE L0–L5 |
| `03-signs/signs/` | 27 个常见标志（MUTCD 形状与颜色） |
| `03-signs/signals/` | 10 种信号灯状态（含闪烁黄箭头、红箭头、停电） |
| `03-signs/markings/` | 8 种路面标线 |
| `04-right-of-way/` | 10 个路权场景（四向停车、T 字路口、环岛、红灯右转、校车、匝道汇入等） |
| `05-laws/` | 驾照分级路线、BAC 刻度、儿童座椅 4 阶段、事故处理 6 步、被警察拦停 5 步、让道法、校车、禁停距离 |
| `06-skills/` | 后视镜调法（传统 vs BGE）、刹车距离、跟车 2 秒 vs 3 秒、变道 SMOG、转弯、高速汇入与驶出、侧方停车 5 步、坡道停车、大货车盲区、环岛、荷兰式开门、视线前瞻、12 种紧急情况 |

字体在页面里使用 Overpass / Noto Sans SC，单独打开 SVG 时会回退到系统字体。法规内容以各州 DMV 手册为准。
