# 咖啡图解：各种咖啡在制备过程中的具体区别

12 张 SVG 图，每张讲清一种冲法（或一类饮品）**哪一步、哪个参数**跟别的不一样。
每张图里的黄色高亮（★ 关键 / 关键差异）就是这一种咖啡最与众不同的地方。

**翻页查看**：用浏览器打开 [index.html](index.html)（需与这些 SVG 放在同一目录），
可以用按钮、键盘 ← → 键或手机左右滑动翻页，“原始大小”按钮可放大查看细节；
网址末尾的 `#espresso`、`#cold-brew` 等可以直接跳到某一张。

## 说明

- 数值是精品咖啡馆和家庭冲煮的**常见范围**，不同豆子、器具、店家会有出入；尤其卡布奇诺、玛奇朵的定义在不同国家差别很大。
- 杯子剖面按成分比例分层示意，真实饮品里浓缩和牛奶是混在一起的；器具图不按真实比例。
- 图中文字使用系统中文字体（苹方 / 微软雅黑 / Noto Sans CJK 等），直接用浏览器打开即可查看。
