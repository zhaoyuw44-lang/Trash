# 理财学习区 (Money Study Section)

这个文件夹专门用于学习金钱与个人理财 (Personal Finance)。笔记、计算表和问答都放在这里，和仓库里的科研文件分开。

## 建议学习路线

1. **基础：现金流 (Cash Flow)**
   - 收入、支出、储蓄率 (Savings Rate)
   - 预算方法：50/30/20 规则、零基预算 (Zero-Based Budgeting)
   - 应急基金 (Emergency Fund)：通常为 3–6 个月的必要支出
2. **债务 (Debt)**
   - 利率 (APR / Interest Rate) 与复利 (Compound Interest)
   - 信用卡、学生贷款 (Student Loans)
   - 还债策略：雪崩法 (Avalanche) 与雪球法 (Snowball)
   - 信用分 (Credit Score)
3. **投资入门 (Investing Basics)**
   - 风险与回报 (Risk vs. Return)、分散投资 (Diversification)
   - 股票 (Stocks)、债券 (Bonds)、指数基金 (Index Funds)、ETF
   - 费用率 (Expense Ratio) 为什么重要
   - 资产配置 (Asset Allocation) 与再平衡 (Rebalancing)
4. **税务与账户 (Taxes & Accounts)**（以美国为例）
   - 401(k) / 403(b)、Roth IRA 与 Traditional IRA
   - HSA、应税账户 (Taxable Brokerage Account)
   - 留学生/签证身份对账户和报税的影响 (Tax Residency)
5. **进阶**
   - 保险 (Insurance)
   - 通货膨胀 (Inflation) 与实际回报 (Real Return)
   - 行为金融 (Behavioral Finance)：常见的心理误区

## 文件夹约定

- `notes/`：按主题写的学习笔记
- `calculators/`：复利、还贷之类的小工具或表格
- `questions.md`：学习中遇到的问题

> 说明：这里的内容用于学习，不构成个性化的投资、税务或法律建议。
