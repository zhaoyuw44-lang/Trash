# 博士毕业去留地图

博士毕业后的交互式规划页：美国签证与绿卡、回国求职与落户、中美教育体系。政策信息核对至 2026-11-12。

- `index.html`：完整页面（含路线助手、OPT/H-1B 日期计算器、优先日查询、行动清单、术语搜索）
- `svg/`：12 张可单独打开的 SVG 图（自动适配浅色/深色模式）
  - 01 决策地图 · 02 F-1→OPT→H-1B 时间轴 · 03 H-1B 加权抽签 · 04 绿卡路径
  - 05 排期距今多久 · 06 回国五步 · 07 中美学术职业阶梯 · 08 中国教育体系
  - 09 中国高校标签 · 10 美国教育体系 · 11 一年关键窗口 · 12 规划甘特图
- `src/template.html` + `build.py`：页面模板与绘图脚本。修改后运行 `python3 build.py` 重新生成 `index.html` 和 `svg/`。

本页用于学习与规划，不构成法律、税务或移民意见；行动前请核对官方最新文件。
